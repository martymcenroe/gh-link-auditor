# LLD-407: pass dead_url to the C5 subagent; align key name with prompt contract

**Issue:** #407
**Status:** Active

## 1. Problem

`score_c5_content_equivalence` (`src/gh_link_auditor/preflight/scores.py:467-474`) invokes the C5 subagent with a context dict of `candidate_url`, `link_text`, `landing_page`. The prompt (`prompts/preflight/content_equiv.txt`, post-#349) documents a contract of `dead_url`, `candidate_url`, `link_text`, `candidate_page`:

- `dead_url` is absent — the subagent cannot perform the URL-pair normalization #349's prompt asks for.
- The landing-page object arrives under the wrong key (`landing_page` vs documented `candidate_page`).

Consequence: the entire #349 prompt tune is a silent no-op. Evidence: post-#349 re-run of `act-now-coalition/covid-data-model` still returns `unrelated` / 65 (report `preflight-20260527T140753Z-113288`).

## 2. Solution

Change only the context dict passed to `sub.run`:

```python
verdict = sub.run(
    prompt_path,
    {
        "dead_url": dead_url,  # NEW — already in scope from the fast-path check
        "candidate_url": candidate_url,
        "link_text": link_text,
        "candidate_page": landing,  # renamed from "landing_page"
    },
)
```

`dead_url` is already extracted at the top of the function for `_are_urls_near_equivalent`; no new plumbing. `RealSubagent.run` JSON-dumps the context verbatim (no template substitution), so the rename is safe at the renderer.

## 3. Tests (TDD — written first, RED against current code)

In `tests/unit/preflight/test_scores.py::TestScoreC5`, using the existing `FakeSubagent` recording boundary:

- `test_c5_passes_dead_url_to_subagent` — asserts `fake.calls[0].context["dead_url"]` equals the candidate's dead URL.
- `test_c5_passes_candidate_page_not_landing_page` — asserts the exact context key set is `{dead_url, candidate_url, link_text, candidate_page}` and that `candidate_page` carries the landing-fetch object. The exact-set assertion pins the prompt-context contract so a future rename can't silently drift again (lesson 2026-05-27: golden-file tests catch prompt drift but not context drift — they're orthogonal).

## 4. Out of scope

- `link_text` is populated from `source_file`, not real anchor text — known limitation, anchor-text capture is #205.
- Prompt content changes — none; #349's prompt already documents this contract.
