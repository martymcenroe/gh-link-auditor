# LLD-426: reconcile abandoned bulk-scan runs to a terminal state

**Issue:** #426
**Status:** Active

## 1. Problem

`bulk_scan_runs` rows whose process died or was abandoned keep their in-flight status forever. Audit 2026-07-28: three of six runs had sat in `checking`/`inventorying` since May with `completed_at=NULL`. Nothing reconciles them, so run listings lie and `--resume-aborted`-style flows (#229) can't see them.

## 2. Solution

Two functions in `bulk_scan/storage.py` plus a CLI subcommand:

- `TERMINAL_RUN_STATUSES = ("done", "aborted", "quality_aborted")` — the exact set `update_run_status` stamps `completed_at` for (single source of truth stays in storage.py).
- `find_abandoned_runs(db, older_than_hours=24.0, now=None)` — non-terminal runs with `started_at` older than the threshold AND no row in `bulk_scan_locks`. The lock is the liveness signal (#244); any locked run is treated as live and never touched — conservative by construction. `now` is injectable for deterministic tests (lesson #433: no wall-clock in unit assertions).
- `reconcile_abandoned_runs(db, older_than_hours=24.0, now=None)` — flips each found run to `aborted` via the existing `update_run_status` (which stamps `completed_at`), with `error = "reconciled: abandoned in status='X' with no activity since <started_at>"`.

CLI: `bulk-scan reconcile [--older-than-hours 24] [--db-path ...] [--apply]` — **dry-run by default** (lists what would flip), `--apply` mutates. Matches the fleet destructive-scripts convention.

## 3. Tests

`tests/unit/bulk_scan/test_reconcile.py` (fixed `NOW`, injected):

- old non-terminal run found; terminal runs not found; young non-terminal not found; locked run not found
- reconcile flips status to `aborted`, sets `completed_at`, writes the explanatory error
- idempotent: second call returns empty
- live/terminal rows byte-untouched after reconcile

`tests/unit/cli/test_bulk_scan_cmd.py`:

- parser registration with defaults (`older_than_hours=24`, `apply=False`)
- dry-run lists but does not mutate; `--apply` mutates

## 4. Out of scope

- Stale-lock cleanup (lock owner's job, #244 territory).
- Auto-reconcile at `bulk-scan start` — deferred until #229's resume flow defines how a resumed run interacts with reconciliation; note added there.

## 5. Acceptance

Mirrors #426: no run older than the threshold remains non-terminal after `reconcile --apply`; live runs provably untouched; unit tests cover threshold, liveness guard, idempotency.
